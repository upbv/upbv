## About

I'm a DevOps / Full-Stack engineer working with cloud infrastructure, automation and backend services. My day-to-day covers infrastructure as code, CI/CD pipelines, and service-oriented backends in Python, Node.js and PHP.

I also build internal tools and automation frameworks. More of my work is on [GitHub](https://github.com/vispce).

## What I Work With

- **Infrastructure & automation** — Ansible, Docker, Kubernetes and Linux / Red Hat systems; CI/CD pipelines and infrastructure as code.
- **Backend** — REST APIs and service-oriented backends in Python, Node.js and PHP.
- **Data** — MySQL schema design, query optimization and data modelling.
- **Web & serving** — Nginx reverse proxying, load balancing and performance tuning; HTML and CSS frontends.
